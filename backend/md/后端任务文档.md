# 知识库管理平台 —— 后端任务文档

> 依据：《后端开发文档.md》v1.2
> 文档版本：v1.0 ｜ 更新日期：2026-08-27
> 说明：本文档将后端开发工作拆解为可执行、可验收的任务清单，含任务拆分、依赖关系、验收要点与排期建议。

---

## 1. 任务总览

| 阶段 | 任务 | 内容概要 | 优先级 |
| --- | --- | --- | --- |
| M1 | 基础设施搭建 | 工程骨架、配置、ORM、数据库迁移、登录与 JWT | P0 本阶段 |
| M2 | 组织与权限 | 部门/角色/用户 CRUD、RBAC、数据权限引擎 | P0 本阶段 |
| M3 | 知识单元 | 知识单元 CRUD、状态管理、数据权限配置 | P0 本阶段 |
| M4 | AI 问答 | 鉴权问答、SSE 流式、日志异步落库 | P0 本阶段 |
| M5 | 数据看板 | 日志聚合、指标、排行、趋势 | P1 本阶段 |
| M6 | 知识沉淀 | FAQ 挖掘/审核/缓存、知识缺口 | P1 本阶段 |
| M7 | 知识入库 | 文档解析、切片、向量化（LangGraph） | P2 后续 |
| M8 | 智能检索 | 混合召回、重排（LangGraph） | P2 后续 |

> 依赖关系：M1 → M2 → M3 → M4 → M5/M6；M7、M8 独立于前序（可并行），但 M4 的简化召回后续需替换为 M8。

## 2. 任务拆解

### M1 基础设施搭建

| 编号 | 任务 | 内容 | 交付物 |
| --- | --- | --- | --- |
| T1.1 | 工程骨架 | 创建项目目录、`pyproject.toml`、`requirements.txt`、`.env.example` | 可启动的空服务 |
| T1.2 | 配置模块 | `core/config.py`（pydantic-settings 读取环境变量） | 配置类 |
| T1.3 | 数据库接入 | SQLAlchemy 异步引擎、会话管理、Alembic 初始化 | DB 连接 + 迁移框架 |
| T1.4 | ORM 模型 | 实现 10 张表的 ORM 模型（`models/` 下） | 模型文件 |
| T1.5 | 建表与种子 | `scripts/init_db.py`、`seed_data.py`（三角色 + 权限码种子） | 初始化脚本 |
| T1.6 | 认证鉴权 | `security.py`（JWT 签发/校验、密码哈希）、`deps.py`、`require_permission` | 认证依赖 |
| T1.7 | 登录接口 | `POST /api/auth/login`，返回 `access_token`/`user_info`/`permissions` | 登录接口 |

**验收要点**：服务可启动；`init_db.py` 一键建表 + 插入三角色；登录返回正确 token 与权限列表。

### M2 组织与权限

| 编号 | 任务 | 内容 | 交付物 |
| --- | --- | --- | --- |
| T2.1 | 部门管理 | 部门树查询、新增、编辑、删除（校验子部门/成员） | 部门接口 |
| T2.2 | 用户管理 | 用户分页列表、新增、编辑、重置密码、启停用 | 用户接口 |
| T2.3 | 角色管理 | 角色列表、新增、编辑、权限分配（覆盖式写入） | 角色接口 |
| T2.4 | RBAC 拦截 | 基于 `role_permissions` 的菜单/操作级权限校验 | 权限拦截器 |
| T2.5 | 数据权限引擎 | `permission_engine.check_units`（四类实体 OR + 部门继承） | 核心鉴权引擎 |
| T2.6 | 权限校验接口 | `POST /api/knowledge/check-permissions` | 鉴权接口 |

**验收要点**：部门树正确；停用用户登录被拒；权限码拦截生效；`check_units` 对 global/部门(含祖先)/角色/个人四类正确放行与拒绝。

### M3 知识单元

| 编号 | 任务 | 内容 | 交付物 |
| --- | --- | --- | --- |
| T3.1 | 单元 CRUD | 分页查询、详情、更新、批量删除 | 知识单元接口 |
| T3.2 | 状态管理 | `status` 字段 `draft/published/archived` 流转 | 状态逻辑 |
| T3.3 | 数据权限配置 | `POST /api/knowledge/units/{id}/permissions` 批量配置四类实体 | 权限配置接口 |
| T3.4 | 导入占位 | `POST /api/knowledge/import` 占位接口（返回未实现提示） | 占位接口 |

**验收要点**：单元 CRUD 正常；详情返回已配置权限列表；权限配置即时生效。

### M4 AI 问答

| 编号 | 任务 | 内容 | 交付物 |
| --- | --- | --- | --- |
| T4.1 | LLM 客户端 | `llm_client.py` 封装外部 API 流式生成 | LLM 客户端 |
| T4.2 | 简化召回 | 本阶段以关键词/最近更新单元作为候选召回 | 召回函数 |
| T4.3 | 鉴权问答 | `ai_service.chat_stream`：登录校验 → 召回 → 鉴权 → 拼装 → 流式生成 | 核心服务 |
| T4.4 | 权限缺失提示 | 无权限召回项在回答中明确提示 | 提示逻辑 |
| T4.5 | 日志落库 | 异步写 `qa_access_logs`（Token/耗时/命中单元） | 日志服务 |

**验收要点**：SSE 流式返回；未授权单元有明确提示；日志异步落库且字段完整。

## 5. 风险与备注

- **数据权限引擎是核心**（M2/T2.5），需优先保证四类实体 OR 逻辑与部门继承正确，建议补充单元测试。
- **AI 问答鉴权闭环**（M4）是本阶段验收重点，简化召回可用，但鉴权链路必须完整。
- **日志落库**（M4/T4.5）需异步化，避免阻塞 SSE 流式响应。
- 外部 LLM/向量 API 需提前确认可用性与协议兼容（OpenAI 兼容），否则 M4/M7 会受阻。
- LangGraph 工作流（M7/M8）本阶段仅预留抽象接口，不阻塞主线交付。
